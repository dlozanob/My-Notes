# Cheesecake Japonés

![](attachments/Pasted%20image%2020260206182322.png)

## Ingredientes

| Ítem           | Cantidad   |
| -------------- | ---------- |
| Huevos         | 4 unidades |
| Mantequilla    | 30 g       |
| Fécula de maíz | 30 g       |
| Queso crema    | 200 g      |
| Leche          | 60 ml      |
| Azúcar         | 60 g       |


>[!Info]
>Cantidad para 2 personas

## Herramientas

| Ítem                                | Cantidad   |
| ----------------------------------- | ---------- |
| Papel parafinado / Papel mantequila | 1 unidad   |
| Moldes para horno                   | 2 unidades |
| Batidora                            | 1 unidad   |
| Horno                               | 1 unidad   |

## Preparación

### Flujo Principal

1. Calentar media olla con agua
	1. Vertir agua calentada en recipiente
2. [Preparación Horno](#Preparación+Horno)
3. [Huevos](#Huevos)
4. [Mantequilla](#Mantequilla)
5. [Base del Postre](#Base+del+Postre)
6. [Recipiente](#Recipiente)
7. Vertir la base dentro de los moldes para horno
8. Hornear postre
	1. Poner el molde dentro del recipiente con agua precalentada (baño de maría)
	2. Poner el recipiente dentro del horno
	3. Hornear a 160 °C por 20-40 minutos
		1. Revisar periódicamente consistencia del postre. Debe estar esponjoso
	4. Sacar recipiente
	5. Repetir proceso

---

### Preparación Horno

1. Encender horno
2. Ajustar temperatura en 160 °C
3. Dejar calentando

### Huevos

1. Preparar recipientes
	1. Recipiente para claras
	2. Recipiente para yemas
2. Separar claras de los huevos
	1. Abrir huevo
	2. Agregar la clara en recipiente de claras
	3. Agregar yema en recipiente de yemas
	4. Repetir el ciclo
3. Batir las claras con batidora por un tiempo hasta que estas se pongan como una espuma sólida

### Mantequilla

1. Colocar 30 g de mantequilla en un recipiente
2. Calentar en el microondas alrededdor de 3 minutos

### Base del Postre

1. Aplicar queso crema a la mantequilla
2. Aplicar fécula de maiz
3. Agregar azúcar (al menos unas 4 cucharadas)
4. Revolver
5. Aplicar claras de huevo sólidas. Debe hacerse lentamente mientras se revuelve
6. Aplicar una yema de huevo
	1. Revolver de manera envolvente por un tiempo
	2. Repetir este ciclo
7. Aplicar esencia de vainilla
8. Revolver

>[!Warning]
>No aplicar todas las yemas de huevo al mismo tiempo, de lo contrario, puede cortarse el postre (fase líquida + fase sólida)

### Recipiente

1. Preparar dos moldes de horno
2. Preparación de los moldes
	1. Cortar el papel de tal manera que envuelva el interior del molde
	2. Envolver el interior del molde con el papel
	3. Repetir proceso
